# Verifikasi dokumen per-berkas (checklist MS/TMS) di tiap tahap operator

Verifikasi dokumen kini bersifat **per-berkas**, menggantikan ADR-0001 (keputusan keseluruhan tanpa status per dokumen). Pada setiap tahap verifikasi (desa → kecamatan → tiap dinas), operator menilai setiap dokumen yang diunggah mahasiswa dengan status `memenuhi` / `tidak_memenuhi` / `belum_dinilai`, tersimpan di tabel `document_verifications` (unik per `document_id` + `stage` + `round`). Catatan wajib saat dokumen ditandai tidak memenuhi syarat. Penilaian disimpan langsung (autosave per klik) dan **terkunci** begitu keputusan tahap (MS/BTL/TMS) disubmit — integritas jejak audit. Saat mahasiswa mengganti berkas atau mengirim ulang setelah BTL, penilaian dokumen direset untuk putaran (`round`) baru; penilaian putaran sebelumnya tetap tersimpan sebagai riwayat dan ditampilkan read-only ke operator tahap berikutnya, operator kabupaten, superadmin, dan mahasiswa. Keputusan aplikasi tetap satu (MS/BTL/TMS) dan tidak otomatis ditentukan oleh checklist; muncul peringatan konfirmasi bila ada dokumen tidak memenuhi syarat namun keputusan tetap MS.
